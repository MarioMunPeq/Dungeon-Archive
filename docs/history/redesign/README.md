# Dungeon Archive Redesign

This directory contains the official Product Design Specification.

The documents are ordered intentionally.

Read them sequentially.

Whenever implementing a feature:

1. Read the relevant specification.
2. Follow its Acceptance Criteria.
3. Reuse the Design System.
4. Preserve consistency.

The specification has priority over implementation assumptions.
